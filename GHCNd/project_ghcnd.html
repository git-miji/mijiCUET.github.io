Project · Machine learning

Weather forecasting from GHCNd climate data

Correlation analysis and predictive modelling on daily climate observations, comparing four model families across snowfall and temperature targets.

Goal

Analyse Global Historical Climatology Network daily (GHCNd) data to find the correlation between meteorological features at a given location, then use machine learning to forecast target features from the remainder.

Approach

Implemented entirely in Python. Data handling and analysis used NumPy, Pandas, Xarray, Cartopy and SciPy; modelling used Scikit-learn; visualisation used Matplotlib, Seaborn and Plotly. Four model families were compared: Decision Tree, Linear Regression, Multi-Output Linear Regression and k-Nearest Neighbours.

Results

For forecasting surface snow thickness and snowfall, the Decision Tree outperformed the alternatives — train MSE 0.000018, test MSE 0.000080, with train and test R² of 0.9333.

For predicting average temperature, k-Nearest Neighbours led with train MSE 2.8635, test MSE 4.6242, and train and test R² of 0.8732.
