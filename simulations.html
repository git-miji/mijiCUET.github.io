Nanoparticle dimer hot-spots

Near-field distribution for a coupled pair of metal nanospheres. As the gap narrows the modes hybridise and field intensity in the junction rises steeply — the effect that underpins SERS.

Solver
Meep — 3-D FDTD
Sweep
Gap 5–60 nm, diameter 40–140 nm
Output
|E/E₀| map, enhancement factor
MeepLSPR

LSPR spectral decomposition

Extinction separated into scattering and absorption components. Small particles are absorption-dominated; larger ones scatter — which decides whether a geometry suits sensing or photothermal use.

Solver
Tidy3D — GPU cloud
Band
450–950 nm
Output
σext, σsca, σabs
Tidy3DSpectra

Metasurface Fano response

Transmission and reflection through a periodic resonator array. Interference between a broad bright mode and a narrow dark mode produces asymmetric, high-Q Fano features.

Solver
Tidy3D — periodic boundaries
Band
150–400 THz
Output
T, R, Q factor
Tidy3DFano

Hybrid waveguide mode

Fundamental mode of a hybrid plasmonic–dielectric guide. The low-index slot pulls the field into a nanoscale region while keeping propagation loss lower than a bare metal guide.

Solver
Meep mode solver
Output
neff, mode area, propagation length
MeepWaveguide

Convergence & resolution study

Relative error against mesh resolution. Metals need fine meshing near surfaces; this establishes the resolution where the result stops changing, so production runs are neither wrong nor wasteful.

Solver
Meep — 8 to 40 px/µm
Checks
Resolution, domain size, PML
MeepVerification

Design-space parameter sweep

Points
2-D grid over gap × diameter
Use
